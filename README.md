# Momo X

Audio product page with scroll-driven 192-frame animation.

**[Live Demo](https://shaisolaris.github.io/momo-audio/)**

## Features

- Scroll-scrubbed 192-frame product animation
- Feature and spec sections
- Gallery and colorway views
- Purchase CTA flows

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
